> *"With great automation comes zero downtime!"* 🕷️

Interactive superhero-themed **DevOps & Site Reliability Engineer Portfolio** featuring 3D WebGL particle physics, interactive cyber terminal HUD, live GitHub API telemetry, dark/classic suit mode switching, and ATS-optimized resume integration.

---

## ⚡ Core Technical Stack

* **Cloud Platforms**: AWS (EKS, EC2, S3, RDS, ECS, Route 53, CloudWatch, SSM), Google Cloud Platform (GCP - GKE, Compute Engine), Azure (Basics)
* **Containers & Orchestration**: Kubernetes (K8s), Docker, Helm Charts, Argo CD, Microservices Architecture
* **Infrastructure as Code (IaC)**: Terraform, AWS CloudFormation, Ansible
* **CI/CD & Automation**: GitHub Actions, GitLab CI/CD, Jenkins Pipelines, AWS CodePipeline, Bash, Python
* **Observability & SRE**: Prometheus, Grafana, AWS CloudWatch, New Relic, Icinga, Root Cause Analysis (RCA)
* **Frontend Core**: Semantic HTML5, Vanilla Modern CSS3 (Glassmorphism & CSS Grid), Three.js (WebGL Web Physics), GSAP

---

## 🚀 Key Features

* 💻 **Interactive DevOps Cyber CLI**: In-browser terminal HUD supporting portfolio commands (`help`, `skills`, `repos`, `career`, `certs`, `whoami`, `theme`).
* 🕸️ **Interactive Web-Shooting & 3D WebGL Canvas**: Three.js particle lattice that reacts elastically to cursor dynamics and triggers acoustic web-swish feedback.
* 🌓 **Dynamic Suit Themes**: Seamless toggle between **Black Suit (Symbiote Mode)** and **Classic Spider-Man Suit Mode** with persistent state.
* 📦 **Live GitHub Repository Telemetry**: Real-time Star ⭐ and Fork 🍴 metrics via GitHub REST API with skeleton loading states.
* 📄 **ATS-Optimized Resume Integration**: Instant download of high-impact PDF resume (`assets/Sam_Sunil_DevOps_Resume.pdf`).
* 🛡️ **Zero-Downtime Error Suite**: Thematic `404.html`, `403.html`, and `maintenance.html` pages.
* 🍪 **Spidey-Sense Cookie Radar**: Lightweight, privacy-respecting cookie preference manager.

## 🛠️ Local Development

Clone the repository and start the local development server:

```bash
# 1. Clone repo
git clone https://github.com/sam-sunil-4/portfolio.git
cd portfolio

# 2. Run local server (with custom 404 fallback)
python3 server.py

# 3. Open browser
open http://localhost:8080
```

---

## 🚀 Deploy to Vercel

```bash
# Deploy with Vercel CLI
npx vercel --prod
```

Or connect the repository on [Vercel Dashboard](https://vercel.com) and deploy with standard static defaults.
